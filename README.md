# MoneyMetrics
**Приветствуем!** \
Мы рады представить наше приложение, которое поможет вам управлять вашими финансами. С его помощью вы сможете легко отслеживать, куда уходят ваши деньги, и анализировать свои расходы.

Основные возможности приложения: \
Учет расходов: Записивайте, сколько и на что вы тратите. \
Статистика: Наглядные графики и отчеты покажут, сколько вы потратили в каждой категории.\
Категории расходов:
  - Еда
  - Одежда
  - Техника
  - Оброзование
  - Транспрот
  - Связь

Наше приложение станет вашими надежным помощником в достижении финансовой стабильности. Планируйте свои финансы проще и эффективнее!
